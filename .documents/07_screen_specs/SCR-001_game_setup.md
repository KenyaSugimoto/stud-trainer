# SCR-001: ゲーム設定画面

## 基本情報

- **画面ID**: SCR-001
- **URL**: `/`
- **目的**: プレイヤー数・ゲームタイプ・初期スタックを設定し、新規ゲームを開始する
- **主CTA**: 「ゲーム開始」ボタン
- **関連フロー**: FLOW-001

## 画面状態

### loading
- **表示要素**: スピナー + 「ハンドを初期化中…」メッセージ
- **発生条件**: ゲーム開始処理実行中
- **ユーザーアクション**: 待機のみ

### empty
- **表示要素**: 全入力欄はデフォルト値または空
- **発生条件**: 初期表示時
- **ユーザーアクション**: 各フォーム入力 → 「ゲーム開始」押下

### error
- **表示要素**:
  - 入力バリデーションエラー（フォーム下に表示）
  - または内部エラー時のエラーメッセージ + 「再試行」ボタン
- **発生条件**:
  - バリデーションエラー（プレイヤー数範囲外、スタック未入力/0以下）
  - ゲーム開始処理の失敗
- **ユーザーアクション**: 入力値修正 → 再度「ゲーム開始」

### success
- **表示要素**: 入力値が有効で CTA が活性化された状態
- **発生条件**: 正常な入力値が設定されている状態
- **ユーザーアクション**: 「ゲーム開始」押下で GameScreen (`/game`) へ遷移

## UI要素

### ページタイトル
- 「Stud Trainer」
- サブタイトル: 「練習用ゲームをセットアップ」

### フォーム要素

1. **プレイヤー数選択**
   - ラベル: 「プレイヤー数」*（必須）
   - コンポーネント: `Select`（2〜7人）
   - バリデーション: 2〜7の範囲

2. **ゲームタイプ選択**
   - ラベル: 「ゲームタイプ」*（必須）
   - コンポーネント: `Select`
   - オプション:
     - Seven Card Stud (Hi)
     - Razz
     - Stud Hi-Lo 8-or-Better

3. **初期スタック入力**
   - ラベル: 「初期スタック」*（必須）
   - コンポーネント: `Input`（数値）+ プリセットボタン（10k / 20k / 30k）
   - バリデーション: 1以上

### 主CTA
- 「ゲーム開始」ボタン
- 全必須項目が有効な場合のみ活性化

## 実装ファイル

- `/src/pages/GameSetupPage.tsx`
- `/src/components/common/FormField.tsx`
- `/src/hooks/useGameStore.tsx`（`startGame` 呼び出し）

- Assumption: プリセットボタンは将来的に設定可能にする可能性あり
