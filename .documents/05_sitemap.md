# サイトマップ（Stud Trainer）

## 1. ページ一覧

| ページ名     | URL    | 説明                                                         |
|--------------|--------|--------------------------------------------------------------|
| ゲーム設定   | /      | プレイヤー数・ゲームタイプ・初期スタックを設定する画面     |
| ゲーム画面   | /game  | 1 ハンドの進行と勝敗・チップ分配を行うメイン画面           |
| （将来）履歴一覧 | /logs  | 保存したハンド履歴を一覧表示（将来拡張）                     |
| （将来）履歴詳細 | /logs/:id | ハンド1件の詳細内容（アクションログなど）を表示（将来拡張） |

## 2. 階層構造（簡易）

```text
/
├─ /game
├─ /logs        (将来)
└─ /logs/:id    (将来)
```

## 3. ページ詳細（繰り返し）

### ゲーム設定
- URL: `/`
- 目的:
  - 新しいゲームの開始条件（人数・ゲームタイプ・初期スタック）を設定する
- 主な要素:
  - プレイヤー数選択（セレクトボックス）
  - ゲームタイプ選択（STUD_HI など）
  - 初期スタック入力欄
  - 「ゲーム開始」ボタン
- 使用 API（任意）:
  - 現状なし（将来、デフォルト設定の取得 API などを追加可能）

### ゲーム画面
- URL: `/`
- 目的:
  - 1 ハンドの進行、アクション入力、勝敗判定、チップ分配を行う
- 主な要素:
  - ゲームタイプ・ステークス表示
  - 現在のストリート表示（3rd / 4th / ... / showdown）
  - 現在アクター（行動プレイヤー名）表示
  - Pot（ポット）表示
  - Winner 表示（handFinished 時）
  - プレイヤー一覧
    - 名前
    - Stack (点数/BB表記)
    - Total Bet This Round
    - Hole Cards / Upcards (カード表示)
      - Hole Cards は自分のみ表示、他プレイヤーのHole Cardsは伏せる
    - Fold 状態表示
      - Folded プレイヤーはカード非表示・灰色化
  - アクションボタン
    - fold / call / bet / raise / complete / bring-in など、許可されたアクションのみ
  - handFinished === false の場合:
    - アクションボタン群表示
  - handFinished === true の場合:
    - Next Hand ボタン表示（クリックで新しいハンド開始）
- 使用 API（任意）:
  - 現状なし（完全ローカル処理）

### （将来）履歴一覧
- URL: `/logs`
- 目的:
  - 過去に保存したハンド履歴を一覧する（フィルタ・ソートなど）
- 主な要素:
  - ハンド一覧テーブル（ゲームタイプ・日時・プレイヤー数・勝者など）
  - 詳細ページへのリンク
- 使用 API（任意）:
  - GET `/api/v1/logs`（将来）

### （将来）履歴詳細
- URL: `/logs/:id`
- 目的:
  - 1 ハンドの詳細（各ストリートでのカード・アクション・スタック推移）を確認
- 主な要素:
  - メタ情報（ゲームタイプ・日時・参加人数など）
  - プレイヤーごとのスタック推移
  - アクションログ（時系列・ストリート別）
- 使用 API（任意）:
  - GET `/api/v1/logs/:id`（将来）
