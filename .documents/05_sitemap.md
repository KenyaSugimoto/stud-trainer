# サイトマップ（Stud Trainer）

## 1. ページ一覧

| ページ名     | URL    | 説明                                                         |
|--------------|--------|--------------------------------------------------------------|
| ゲーム設定   | /      | プレイヤー数・ゲームタイプ・初期スタックを設定する画面     |

## 3. ページ詳細（繰り返し）

### ゲーム設定
- URL: `/`
- 目的:
  - 新しいゲームの開始条件（人数・ゲームタイプ・初期スタック）を設定する
- 主な要素:
  - プレイヤー数選択（セレクトボックス）
  - ゲームタイプ選択（STUD_HI など）
  - 初期スタック入力欄
  - 「ゲーム開始」ボタン
- 使用 API（任意）:
  - 現状なし（将来、デフォルト設定の取得 API などを追加可能）

### ゲーム画面
- URL: `/`
- 目的:
  - 1 ハンドの進行、アクション入力、勝敗判定、チップ分配を行う
- 主な要素:
  - ポーカーテーブル表示
    - テーブル背景（フェルト + リング）
    - 座席配置（7-maxの円形レイアウト）
    - 中央情報 & ベット/アンティ表示
    - ポット表示
    - プレイヤー情報表示
      - 名前
      - Stack (点数/BB表記)
      - Total Bet This Round
      - Hole Cards / Upcards (カード表示)
        - Hole Cards は自分のみ表示、他プレイヤーのHole Cardsは伏せる
      - Fold 状態表示
        - Folded プレイヤーはカード非表示・灰色化
    - アクションボタン群
      - fold / call / bet / raise / bring-in / complete / check など、許可されたアクションのみ
  - ゲームタイプ・ステークス表示
  - 現在のストリート表示（3rd / 4th / ... / showdown）
  - 現在アクター（行動プレイヤー名）表示
  - Winner 表示（handFinished 時）
- 使用 API（任意）:
  - 現状なし（完全ローカル処理）
